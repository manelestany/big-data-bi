## Big Data con mis palabras
 
**Qué es Big Data:Un pack de datos que no se pueden gestionar con herramientas convencionales**
 
**Un ejemplo que sí es Big Data, y por qué:gestionar datos masivos de un cliente para identificar que trabajadores son susceptibles a x bonos. Creo que es big data por la cantidad de datos y porque se obtienen de distintas fuentes, como pdfs, imagenes, tablas y texto**
 
**Un ejemplo que no es Big Data, y por qué:datos de facturacion de un cliente, hay pocas lineas y se puede gestionar con un excel tranquilamente**
